# 🧑‍💻 Aman Bucha — Portfolio

This is my personal portfolio website built using **Astro** and **TailwindCSS**, showcasing my experience, projects, blogs, and talks.  
Deployed using **GitHub Pages**.

👉 **Live at:** [amanbucha.github.io](https://amanbucha.github.io)

---

## 🧩 Local Development

```bash
# install dependencies
npm install

# run dev server
npm run dev

# build for production
npm run build
```
